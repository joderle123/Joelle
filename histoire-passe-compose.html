🎯 Le Passé Composé - C'est quoi?

Le passé composé, c'est comme une machine à remonter le temps! On l'utilise pour parler de choses qui se sont passées AVANT maintenant.

Exemple: "Hier, j'ai mangé une pizza." 🍕

🔧 La Formule Magique

Pour construire le passé composé, tu as besoin de 2 ingrédients:

SUJET + AVOIR / ÊTRE + PARTICIPE PASSÉ

🌟 Avec AVOIR (la plupart des verbes)

J' ai mangé
Tu as mangé
Il/Elle a mangé
Nous avons mangé
Vous avez mangé
Ils/Elles ont mangé

🏠 Avec ÊTRE (verbes de mouvement)

Certains verbes utilisent ÊTRE au lieu de AVOIR. Retiens la maison d'être:

🚶 aller, venir, arriver, partir, entrer, sortir, monter, descendre, tomber, rester, naître, mourir

Je suis tombé(e)
Tu es tombé(e)
Il/Elle est tombé(e)
Nous sommes tombé(e)s
Vous êtes tombé(e)s
Ils/Elles sont tombé(e)s

🎨 Les Terminaisons du Participe Passé

-ER → -É
manger → mangé
regarder → regardé
-IR → -I
finir → fini
choisir → choisi
Irréguliers 🎲
faire → fait
être → été
